# Curious Tech - Educational Platform
## Theme 
Curious Tech is a theme-based educational platform designed to empower students in advanced technology fields. It bridges the gap between theoretical knowledge and practical execution, focusing on Artificial Intelligence, Cybersecurity, and Software Architecture.
## Features
* **Authentication System:** Secure registration and login modules.
* **Interactive Evaluation:** A JavaScript-powered quiz that grades user knowledge.
* **Premium Access Control:** Role-based UI that unlocks simulators and transmissions upon login.
* **Responsive Design:** A custom Neo-Brutalist aesthetic that adapts to all screen sizes.
* **Dynamic Animations:** CSS keyframes including page transitions and pulsing alerts.

## Technologies Used
* **HTML5:** Semantic structuring and form building.
* **CSS3:** Custom variables, grid/flexbox layouts, media queries, and keyframe animations.
* **Vanilla JavaScript:** DOM manipulation, form validation, and state management using `localStorage` and `sessionStorage`.
