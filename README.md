# Curious Tech

A custom frontend web project designed to showcase responsive layouts, interactive user interfaces, and structured content delivery. 

## Technical Stack
* **Languages:** HTML5, CSS3, JavaScript
* **Styling:** Custom semantic CSS (No heavy UI frameworks)

## Key Features
* **Authentication UI:** A structured, custom-built login interface frontend.
* **Dynamic Content Sections:** Dedicated, responsive layouts designed specifically for transmission blogs, project showcases, and an 'About' module.
* **Clean Architecture:** Focus on readable, human-driven HTML and CSS logic rather than auto-generated boilerplate.
